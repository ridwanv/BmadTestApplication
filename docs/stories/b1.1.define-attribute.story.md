# Story B1.1: Define Attribute

<!-- Powered by BMAD™ Core -->

## Status
Ready for Development

## Story
**As an Architect,**
**I want to** create attribute definitions (datatype, mandatory, allowed values, regex),
**so that** I can flexibly extend the system registry with new attributes and validation rules.

## Acceptance Criteria
- Given I'm on **/attributes/create**
  When I set Name, DataType, Rules
  Then the definition is saved and active

## Tasks / Subtasks
- [ ] Design attribute definition data model (Name, DataType, Mandatory, AllowedValues, Regex)
- [ ] Implement backend API for creating attribute definitions
- [ ] Implement validation service integration for rules
- [ ] Create UI for /attributes/create with form fields and validation
- [ ] Save new attribute definition and activate
- [ ] Write unit tests for attribute creation and validation

## Dev Notes
- Attribute definitions must support extensibility for future attribute types
- Validation service should enforce rules at both API and UI layers
- Audit log all attribute definition changes
- Follow Clean Architecture and CQRS patterns
